# CineMatch API

FastAPI backend for the CineMatch AI Movie Recommendation engine.

- **TF-IDF**: Fast lexical similarity across 87k movies
- **BERT**: Deep semantic neural embeddings (all-MiniLM-L6-v2, 384d)

API docs available at `/docs`.
